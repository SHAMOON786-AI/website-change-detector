# 🧩 Website Change Detector — Browser Extension

A lightweight companion Chrome / Edge / Brave extension that allows you to start monitoring any webpage you're currently viewing with a single click.

---

## 🚀 How to Install (Takes 30 seconds)

1. Open your browser and navigate to:
   * **Chrome / Brave:** `chrome://extensions`
   * **Edge:** `edge://extensions`
2. Enable **Developer mode** (toggle switch in the top-right corner).
3. Click the **"Load unpacked"** button in the top-left corner.
4. Select this `extension` folder (`website-change-detector/extension`).
5. The **Website Watch** extension icon will now appear in your browser toolbar!

---

## ⚡ How to Use

1. Navigate to any website you want to track (e.g. an e-commerce product, news page, blog post).
2. Click the **Website Watch** icon in your browser toolbar.
3. The page URL and title are automatically filled in.
4. (Optional) Choose a check interval, specify keyword alerts, or set a CSS selector.
5. Click **🚀 Monitor This Page**.
6. The page is instantly queued in your Website Change Detector dashboard!
